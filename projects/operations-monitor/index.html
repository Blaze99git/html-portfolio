What this demonstrates

A responsive operations view with a Python JSON API, SQLite persistence, generated station telemetry, OEE and quality calculations, acknowledged alerts, and CSV export. Start the API locally to see the dashboard update from stored readings.

Run the full system

From the repository root, run python3 projects/operations-monitor/server.py, then open http://127.0.0.1:8100/projects/operations-monitor/. The server exposes a versioned API at /api/v1/, starts a telemetry simulator, and stores its local database in the project’s ignored data/ folder. See the project README for routes and design boundaries.

What this demonstrates

A responsive operations view with a simulated production signal, line-level KPIs, station status, events, and CSV export. Time-range and pause controls update the displayed model without relying on an external service.

Architecture notes

  • Sample signal names and relational schema are included in the project source.
  • SQL files define stations, work orders, telemetry, events, and example reporting queries.
  • A production deployment would require validated Ignition tags, access controls, and plant-specific review.

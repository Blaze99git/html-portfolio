Prototype boundaries

Fictional content: all procedures and examples were written for this demonstration. The browser build uses a small local retrieval routine; a local Python API is included as an alternative runner. There is no connected model or production integration.

PYTHON 3RAG PATTERNCITATIONSLOCAL DATA

What this demonstrates

Document discovery, lexical retrieval, relevance ranking, short evidence-backed responses, and visible source attribution. The same JSON knowledge base can be queried through the browser implementation or Python standard-library API.

PYTHONJSONHTML / CSS / JSTF-IDF STYLE RANKING

Run locally

From the portfolio repository root, run python3 projects/industrial-knowledge-assistant/run_demo.py, then open http://127.0.0.1:8000/projects/industrial-knowledge-assistant/. No package install, API key, or external service is needed.

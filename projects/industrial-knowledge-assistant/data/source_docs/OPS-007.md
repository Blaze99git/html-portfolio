---
id: OPS-007
title: PLC tag quality and stale values
category: data
section: Signal health
revision: 1.0
---
A dashboard value should be treated as stale when its source timestamp exceeds the configured freshness window or the PLC quality flag indicates an invalid sample. Display the latest timestamp and quality state with the value. Do not substitute a prior good reading without making its age visible. Log the tag name, source system, last update time, and quality code so the controls team can investigate the communication path.

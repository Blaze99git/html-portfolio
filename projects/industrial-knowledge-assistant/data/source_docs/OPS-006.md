---
id: OPS-006
title: Weld retry and parameter review
category: quality
section: Weld cycle exception
revision: 1.0
---
If a weld cycle returns a retry result, keep the unit in its current controlled location and follow the approved inspection plan for that product. Record the weld station, unit trace identifier, cycle time, retry count, and displayed result in the quality log. Do not change weld parameters or repeat a cycle outside the approved process. Notify the quality representative when the retry limit is reached, a trace result is missing, or the same condition repeats.
